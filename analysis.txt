SYSTEMS
=======

1. LOCAL FPS CONTROLLER
-----------------------
Classes: CharacterMovement, FirstPersonCamera, HeadBobbing, PlayerInputHandler, IControlable

Fully standalone — zero networking code. PlayerInputHandler bridges Unity's PlayerInput callbacks
to the movement/camera components. NetFpsPlayerAdapter enables/disables these components based on
IsOwner, acting as a clean adapter that never touches the FPS code itself.

  IControlable (interface)
    Methods: SetMovementInput, SetLookInput, SetSprinting, SetCrouching, Jump

  CharacterMovement : MonoBehaviour, IControlable
    Physics-based movement via CharacterController. Handles sprint/crouch/jump.

  FirstPersonCamera : MonoBehaviour
    Yaw/pitch look using LateUpdate. Receives look input from outside.

  HeadBobbing : MonoBehaviour
    Reads CharacterController.velocity to oscillate camera position.

  PlayerInputHandler : MonoBehaviour
    Bridges Unity's PlayerInput (New Input System) callbacks to CharacterMovement and
    FirstPersonCamera. Requires PlayerInput component.
    Callbacks: OnMove, OnCamera, OnSprint, OnCrouch, OnJump


2. NETWORKING ROOT & TRANSPORT
-------------------------------
Chain: NetGameRoot → SteamLobbyNetcode → FacepunchTransport → Steam P2P

  NetGameRoot (Singleton, MonoBehaviour)
    Owns NetworkManager, FacepunchTransport, NetPlayerRegistry, NetSceneFlow,
    SteamBootstrap, SteamLobbyNetcode refs.
    Exposes Host() / Shutdown().
    Fires StateChanged event.
    Enum NetGameState: Offline, Hosting, Connecting, InSession

  SteamLobbyNetcode (MonoBehaviour)
    Creates/joins a Steam lobby and calls NetworkManager.StartHost() / StartClient().
    Encodes NetConnectionPayload into NetworkConfig.ConnectionData.
    Hooks SteamFriends.OnGameLobbyJoinRequested for Steam friend invites.

  SteamBootstrap (MonoBehaviour, ExecutionOrder -1000)
    Optionally initializes SteamClient. Fires ReadyChanged event.

  SteamIdentityProvider : MonoBehaviour, INetIdentityProvider
    TryGetLocalIdentity() returns SteamClient.SteamId + SteamClient.Name.

  NetConnectionApproval (MonoBehaviour)
    Hooks NetworkManager.ConnectionApprovalCallback.
    Enforces: build version match, max player cap, no-late-join (via NetSceneFlow.Phase).

  NetConnectionPayload (struct)
    JSON-encoded payload: buildVersion, platformUserId, displayName.


3. PLAYER REPRESENTATION
-------------------------
  NetPlayer (NetworkBehaviour)
    NetworkVariable<ulong> _platformUserId
    NetworkVariable<FixedString64Bytes> _displayName
    NetworkVariable<bool> _isReady
    SubmitIdentityServerRpc() — sends identity on spawn.
    ToggleReady() (owner-only) / ServerSetReady(bool) (server-only).
    Registers/unregisters itself with NetPlayerRegistry on spawn/despawn.

  NetPlayerRegistry (MonoBehaviour, non-networked)
    Fires PlayerAdded, PlayerRemoved, PlayerUpdated events.
    Exposes AreAllReady.
    Consumed by: NetLobbyRosterTMP, NetLobbyReadyPlatform, NetReadyPlatformGate.

  NetFpsPlayerAdapter (NetworkBehaviour)
    On IsOwner: enables PlayerInput, PlayerInputHandler, CharacterMovement,
                FirstPersonCamera, HeadBobbing, Camera, AudioListener.
    On !IsOwner: disables all of the above + disables other scene cameras/listeners.

  NetLocalCameraEnforcer (NetworkBehaviour)
    Hooks SceneManager.sceneLoaded + activeSceneChanged.
    Re-enforces owner camera exclusivity for a configurable window after scene load.


4. SCENE & SESSION FLOW
------------------------
Two overlapping orchestration layers representing successive design iterations:

  NetSceneFlow (MonoBehaviour) — low-level
    Tracks NetRunPhase (Hub / InRun).
    Hooks NetworkManager.OnServerStarted and NetworkSceneManager.OnSceneEvent.
    Fires PhaseChanged event.
    TryStartRun() / TryReturnToHub().

  NetGameSession (NetworkBehaviour, Singleton) — high-level
    NetworkVariable<NetSessionPhase>: Lobby, LoadingRun, InRun, ReturningToLobby.
    Fires PhaseChanged event.
    Handles additive Dungeon scene load/unload.
    ServerTeleportAllPlayers() via NetSpawnPointGroup.
    RPCs: RequestStartRunServerRpc, RequestReturnToLobbyServerRpc.

  NetRunSessionController (MonoBehaviour, Singleton) — top-level coordinator
    Wires NetReadyPlatformGate (start + return) → NetElevatorDescentController
    → NetworkSceneManager in coroutine sequences.
    Waits for LoadEventCompleted + elevator stop before advancing phase.
    ServerExecuteCommand(NetSessionAutoCommand): Auto, StartRun, ReturnToHub.

  NetSpawnPointGroup (MonoBehaviour)
    Array of Transform spawn points tagged with NetSpawnContext (Lobby / Run).
    TryGetSpawnPoint(clientId) = points[clientId % points.Length].
    Draws gizmos in editor.

  NetElevatorDescentController (NetworkBehaviour)
    Server-only ServerMoveBy(distance, duration).
    SmoothStep easing via coroutine. Exposes IsMoving.


5. INTERACTION SYSTEM (TWO-GENERATION)
----------------------------------------

NEW PIPELINE (preferred):

  PlayerInteractor → RequestUseNewAdapterServerRpc
    → NetInteractableAdapter.TryUseServer()
      → InteractableCore.TryUseInternal()
        → InteractionActionCore.Execute(ctx)  [ScriptableObject asset]
          → ctx.State (= NetInteractableAdapter) writes NetworkVariables

  IInteractableState (interface)
    Slots: BoolState, IntState, FloatState

  InteractableCore : MonoBehaviour, IInteractableState
    Holds InteractionBinding[] (verb → InteractionActionCore[]).
    TryUseLocal() for solo, TryUseInternal() for both.
    Manages Dictionary<int, Coroutine> tween runner (RunTween).

  InteractionContextCore (readonly struct)
    Carries: Target, Interactor, InteractorClientId, Verb, State, IsServerAuthoritative.

  InteractionActionCore : ScriptableObject (abstract)
    CanExecute(ctx) + Execute(ctx). Actions are assets, not scene components.

  DoorToggleRotateActionCore : InteractionActionCore
    Toggles BoolState. Computes open/closed Quaternion from cached closed rotation
    + openLocalEulerOffset. Runs tween via InteractableCore.RunTween.

  ToggleBoolStateActionCore : InteractionActionCore
    Toggles or sets BoolState.

  NetInteractableAdapter : NetworkBehaviour, IInteractableState
    Wraps InteractableCore with 3 NetworkVariables (bool, int, float).
    TryUseServer() delegates to InteractableCore.TryUseInternal() passing
    itself as state, so actions write to replicated vars.

DEPRECATED PIPELINE (dEPRECAT/, still compiled):

  PlayerInteractor → RequestUseLegacyServerRpc
    → NetInteractable.TryUseServer()
      → InteractionAction.Execute(ctx)

  NetInteractable (NetworkBehaviour)
    Embedded NetworkVariable<bool/int/float>. Server-only TryUseServer().

  InteractionAction (ScriptableObject, abstract)
    Uses InteractionContext (holds NetInteractable Target, NetworkObject Interactor).

  DoorRotateToggleAction    — writes transform.localRotation (relies on NetworkTransform)
  NetPickupAction           — despawns target NetworkObject
  NetToggleBoolAction       — toggles NetInteractable.BoolState
  DebugIncrementCounterAction — increments NetInteractable.IntState
  ElevatorSessionAutoCommandAction — calls NetRunSessionController.ServerExecuteCommand()
  ElevatorStartRun          — checks NetLobbyReadyPlatform.AllReadyConfirmedServer (stubbed)


6. READY GATE
--------------
  NetReadyPlatformGate (MonoBehaviour)
    Trigger collider tracking per-client overlap counts.
    Modes: HubOnly, InRunOnly, HubAndRun.
    When all registered players inside for confirmCountdownSeconds:
      AllReadyConfirmedServer = true.
    Optionally syncs state to NetInteractable.BoolState for UI replication.
    Consumed by NetRunSessionController.CanStartRunServer().

  NetLobbyReadyPlatform (MonoBehaviour) — older version
    Calls NetPlayer.ServerSetReady(true/false) on trigger enter/exit.
    Consumed by ElevatorStartRun action.

  NetSpawnPointGroup (MonoBehaviour)
    TryGetSpawnPoint(clientId) = points[clientId % count].


7. STEAM VOICE CHAT
--------------------
Hub-and-spoke relay via NGO's CustomMessagingManager:

  Client:
    NetSteamProximityVoiceChat.Update()
      SteamUser.ReadVoiceData()
      → SendNamedMessage("SteamVoice_C2S") to server

  Server:
    OnVoiceFromClient()
      → relay "SteamVoice_S2C" to all other clients

  Client (receiver):
    OnVoiceFromServer()
      → find player NetworkObject by clientId
      → SteamUser.DecompressVoice() → PCM16 to float
      → SteamVoiceSpeaker.PushSamples()  [if within decodeDistanceMax]

  SteamVoiceSpeaker (MonoBehaviour)
    Ring-buffer streaming AudioClip. OnAudioRead() callback drains buffer.
    3D spatial AudioSource. On data receipt:
      → pings VoiceTalkIndicator (sprite swap: mouthClosed / mouthOpen)
      → pings MouthBlendshapeTalkAnimator (blend shapes on SkinnedMeshRenderer)

  MouthBlendshapeTalkAnimator (MonoBehaviour)
    Drives two blend shapes (close/open) via smooth lerp.
    Supports: ping-hold mode, SetTalking(bool), SetTalkLevel01(float amplitude).
    Optionally oscillates open weight via sine wave to simulate speech.

  Configuration: NetSteamVoiceConfig (ScriptableObject)
    sendIntervalSeconds, maxChunkBytes, bufferSeconds, prefillSeconds,
    talkerActiveSeconds, fadeIn/OutSeconds, rebufferOnUnderrun,
    hubSpatialBlend (2D), runSpatialBlend (3D), runMaxDistance, runMinDistance.


8. UI
------
  NetDemoUI (MonoBehaviour)
    Debug-only. Host button → NetGameRoot.Host(). Status text polls GetDebugStatus() each frame.

  NetLobbyRosterTMP (MonoBehaviour)
    Subscribes to NetPlayerRegistry.PlayerAdded/Removed/Updated.
    Renders roster via TMP_Text: host marker, display name, ready state.
    Ready button → NetPlayer.ToggleReady().
    Start button → NetGameSession.RequestStartRun() (host only, when CanStartRun()).

KEY ARCHITECTURAL PATTERNS
===========================

Adapter pattern
  FPS controller has no net code. NetFpsPlayerAdapter wraps it by toggling component
  enabled-states based on IsOwner — solo code stays unmodified.

Server authority
  All writes guarded by if (!IsServer). Clients request actions via [ServerRpc].
  Connection approval enforces version and player cap before client is admitted.

ScriptableObject actions
  Interaction actions are assets, not scene components. Easy to swap/configure per
  interactable in the Inspector without code duplication.

Two-generation interaction pipeline
  dEPRECAT/ pipeline still fully functional alongside the new one.
  PlayerInteractor detects both pipelines and routes accordingly.
  New pipeline cleanly separates state (IInteractableState) from transport
  (NetworkVariable vs local field).

Scene flow duplication
  NetSceneFlow and NetGameSession both track run phase — successive design iterations.
  NetRunSessionController is the current top-level coordinator using NetSceneFlow
  as its phase source.

Config-driven tunables
  NetGameConfig and NetSteamVoiceConfig ScriptableObjects centralize all settings,
  keeping magic numbers out of MonoBehaviours.

Voice distance culling
  Decoding is skipped if speaker is beyond decodeDistanceMax, saving CPU.
  Spatialization switches from 2D (hub) to 3D (dungeon) via NetSteamVoiceConfig.
